# Regression-Analytics-Using-SAS
Regression Analytics Project on SAS
This project demonstrates the application of regression techniques in SAS to analyze and model data. The analysis focused on:

    Stepwise Regression – Iteratively selecting predictors based on statistical significance to build parsimonious models.

Model Selection with SBC (Schwartz’s Bayesian Criteria) – Comparing alternative models to identify the one with the best trade-off between complexity and fit.

Outlier and Leverage Diagnostics – Detecting influential data points that may distort regression estimates.

    The project files include:

SAS output for stepwise regression models.

Diagnostic results for outlier and leverage points.

Model comparisons using Bayesian criteria.

     Key Learning Outcomes

Practical application of regression analysis in SAS.

Understanding model selection trade-offs.

Detecting and addressing influential observations in regression modeling.

This repository showcases a hands-on approach to data modeling and diagnostics using SAS, useful for students, data analysts, and statisticians learning applied
